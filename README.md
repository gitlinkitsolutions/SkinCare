## About

**GitLink Hair & Skin Care Clinic** is a premium aesthetic medical clinic website based in Dhaka, Bangladesh. We offer a comprehensive range of beauty and medical treatments including hair care, skin care, laser treatments, anti-aging services, bridal packages, and wellness spa offerings.

---

## Features

### Services

| Category | Treatments |
|----------|------------|
| **Hair Care** | PRP Therapy, Hair Transplant, Hair Spa, Mesotherapy, Scalp Pigmentation |
| **Skin Care** | Signature Facial, Chemical Peel, Microdermabrasion, HydraFacial, Acne Treatment |
| **Laser Treatments** | Hair Removal, Skin Resurfacing, Pigmentation Correction |
| **Anti-Aging** | Botox, Dermal Fillers, Thread Lift, RF Skin Tightening, PRP Facial |
| **Bridal Packages** | Pre-wedding treatments, Wedding day packages |
| **Wellness & Spa** | Massages, Aromatherapy, Body Treatments |

### Interactive Features

- **Booking Modal System** — Multi-step consultation booking with form validation
- **Animated Statistics Counter** — Numbers count up when scrolled into view
- **Service Carousel** — Auto-play carousel for services and packages
- **Gallery with Filters** — Category-based filtering (Hair, Skin, Laser, Spa)
- **AI Skin Analyzer** — Visual demo section with scan animation
- **Toast Notifications** — Success/error feedback for form submissions
- **Mobile Responsive Menu** — Slide-out drawer with overlay
